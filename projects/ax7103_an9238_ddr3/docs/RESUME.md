# 简历表述

- **系统实现**：基于Artix-7与Xilinx XDMA搭建PCIe Endpoint高速数据采集平台，完成AN9238采集控制、数据缓存管理及DMA传输通路设计；通过AXI-Lite寄存器实现PC端对采集长度、工作模式和运行状态的配置，并将采样数据通过XDMA C2H通道上传至主机。
- **项目成果**：支持真实模拟信号采集和内部高速数据测试两种模式，PC端可完成板卡控制、DMA数据接收、波形显示、文件保存及正确性校验；PCIe配置为Gen2 x4，XDMA用户侧采用128 bit、125 MHz接口，理论带宽达到2 GB/s，满足65 MSPS采样数据的实时传输需求。

完成Vivado和实板验证前，不应在简历中追加“实测达到某速率”或“完成上板联调”。
