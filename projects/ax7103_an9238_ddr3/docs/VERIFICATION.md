# 验证记录与计划

## 已完成

2026-09-16在Icarus Verilog下完成：

- 全部可移植RTL和Block Design适配层成功展开；
- 80字节写入从`0xFF0`开始时，自动拆成1拍和4拍两个突发；
- AN9238模型采集8组数据，生成2个128-bit缓存字；
- 非16字节对齐长度被拒绝；
- 仿真输出：`PASS: burst split, capture packing and argument checks`。

Icarus关于`always_comb`常量选择的提示是模拟器能力提示，不是编译失败。

## 尚未完成

当前机器没有Vivado和AX7103实板，因此以下项目必须在目标环境继续执行：IP生成、MIG校准、综合实现、时序收敛、bitstream生成、PCIe枚举、驱动加载、真实模拟采集和吞吐实测。简历中的“上板完成”与实测速率只能在这些测试结束后填写。

## 建议验收项

- Ramp模式64 MiB循环100次零错误；
- ADC模式采样计数、文件长度和通道格式一致；
- C2H分别测试1 MiB、64 MiB和256 MiB；
- 记录平均/最低吞吐率，而不是只记录峰值；
- 制造错误长度和异常复位，确认错误位可观察且可清除。
