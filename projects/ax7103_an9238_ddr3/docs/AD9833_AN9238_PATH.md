# AD9833与AN9238模拟采集链路

## 实际连接

```text
PC写AXI-Lite寄存器
        |
        v
ad9833_controller --SPI--> AD9833模块 --模拟信号--> AN9238 CH0 SMA
                                                   |
                                                   v
                                      an9238_capture -> DDR3 -> XDMA C2H -> PC
```

AD9833与AN9238不是同一条数字总线：FPGA只通过三根SPI信号配置AD9833，AD9833产生的模拟输出再接到AN9238的模拟输入。AN9238把模拟波形转换成12-bit并行采样数据。

## J11上的AD9833控制线

| 功能 | AX7103 J11 | FPGA管脚 | 方向 |
|---|---:|---|---|
| `DDS_SCLK` | 3 | P16 | FPGA到AD9833 |
| `DDS_FSYNC_N` | 4 | R17 | FPGA到AD9833 |
| `DDS_SDATA` | 5 | R16 | FPGA到AD9833 |
| GND | 1、37或38 | - | 共地 |

J13保留给AN9238数据与采样时钟，不与上述J11信号复用。AD9833模块应支持3.3 V数字输入；模块供电按其原理图选择，不能把5 V逻辑送入FPGA。模拟输出与AN9238必须共地，幅值、共模和输入范围必须先核对模块手册，必要时增加衰减、偏置或差分驱动。

## RTL行为

`ad9833_controller.sv`在一次`apply_i`后发送5个16-bit控制字：复位控制字、频率低14位、频率高14位、相位字和最终波形控制字。频率调谐字计算公式为：

```text
FTW = round(f_out * 2^28 / MCLK)
```

`DDS_FTW`保存28-bit FTW；写`DDS_CONTROL.APPLY`产生一次配置脉冲。`STATUS.DDS_BUSY`表示SPI正在发送，`STATUS.DDS_DONE`表示最近一次配置完成。

## 上板顺序

1. 先用内部Ramp模式验证PCIe、DDR3和XDMA通路。
2. 断电连接AD9833的SPI、供电和公共地，并将其模拟输出接AN9238 CH0。
3. 使用低频、低幅正弦波起步，例如在25 MHz MCLK条件下配置100 kHz。
4. 示波器先确认AD9833输出，再运行ADC采集，避免把模拟接线问题误判成PCIe问题。
